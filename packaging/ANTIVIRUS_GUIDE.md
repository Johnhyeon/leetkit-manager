# 백신·SmartScreen 경고가 뜰 때

LeetKit Manager를 처음 실행할 때 Windows가 경고를 띄우거나, 백신이 파일을 차단·삭제할 수
있습니다. **바이러스가 아니라 오탐(誤探)입니다.** 왜 그런지와 해결 방법을 아래에 정리했습니다.

---

## 왜 이런 일이 생기나요

두 가지 다른 경고가 있고, 원인도 다릅니다.

**1. "Windows에서 PC를 보호했습니다" (SmartScreen)**

프로그램에 **코드 서명 인증서**가 없어서 뜹니다. 개인 개발자가 인증서를 발급받으려면 연
수십만 원이 들어서, 아직 적용하지 않았습니다. 프로그램이 위험해서가 아니라 "누가 만들었는지
Windows가 보증할 수 없다"는 뜻입니다.

**2. 백신이 차단하거나 자동 삭제함**

LeetKit Manager는 파이썬 프로그램을 실행 파일 하나로 압축해 만들었습니다(PyInstaller).
이 방식은 실행할 때 내부 파일을 임시 폴더에 풀고 실행하는데, **일부 악성코드도 똑같은 구조를
쓰기 때문에** 백신이 "행동이 비슷하다"는 이유로 잡아냅니다. 실제 악성 코드가 발견된 게
아니라, 생김새만 보고 걸러낸 것입니다.

---

## 1. SmartScreen 통과하기

1. "Windows에서 PC를 보호했습니다" 창에서 **추가 정보** 클릭
2. 아래에 나타나는 **실행** 버튼 클릭

한 번만 하면 그 다음부터는 안 뜹니다.

---

## 2. Windows Defender에 예외 등록하기

Defender가 파일을 지워버렸다면 먼저 복구해야 합니다.

**차단된 파일 복구**
1. 시작 메뉴 → **Windows 보안** 실행
2. **바이러스 및 위협 방지** → **보호 기록**
3. 목록에서 LeetKitManager 항목 클릭 → **작업** → **허용**

**미리 예외로 등록해두기**
1. **Windows 보안** → **바이러스 및 위협 방지**
2. "바이러스 및 위협 방지 설정" 아래 **설정 관리** 클릭
3. 아래로 스크롤 → "제외" 항목의 **제외 추가 또는 제거**
4. **+ 제외 추가** → **파일** 선택
5. `LeetKitManager.exe`를 선택

> 폴더째 예외로 두고 싶다면 4번에서 **폴더**를 골라 프로그램이 있는 폴더를 지정하세요.

---

## 3. 다른 백신을 쓰는 경우

제품마다 메뉴 이름이 다르지만 흐름은 같습니다 — **"예외/제외/신뢰할 수 있는 항목"** 에
`LeetKitManager.exe`를 추가하면 됩니다.

| 백신 | 메뉴 위치 |
|---|---|
| V3 (안랩) | 환경설정 → 검사 예외 설정 → 파일·폴더 추가 |
| 알약 | 환경설정 → 검사 → 예외 설정 → 추가 |
| Avast / AVG | 메뉴 → 설정 → 예외 → 예외 추가 |
| Norton | 설정 → 바이러스 백신 → 검사 및 위험 → 제외 항목 |
| Kaspersky | 설정 → 위협 및 제외 → 제외 관리 |

---

## 4. 파일이 진짜 맞는지 확인하고 싶다면

배포 페이지에 함께 올라간 `LeetKitManager.exe.sha256` 파일의 값과 대조하면, 받은 파일이
중간에 변조되지 않았음을 확인할 수 있습니다.

PowerShell에서:

```powershell
Get-FileHash LeetKitManager.exe -Algorithm SHA256
```

출력된 값이 `.sha256` 파일 안의 값과 같으면 정상입니다.
