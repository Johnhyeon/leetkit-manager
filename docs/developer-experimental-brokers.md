# 실험 증권사 개발자 노출

1.0 고객 모드에는 KIS와 키움만 표시한다. 토스 어댑터, 자격 증명 계약, 보안 테스트와 공급자 테스트 코드는 삭제하지 않고 실험 상태로 유지한다.

개발 중 실험 공급자를 노출할 때 StockLens와 LeetKit Manager를 시작하는 같은 환경에 다음 값을 명시한다.

```powershell
$env:LEETKIT_ENABLE_EXPERIMENTAL_BROKERS = '1'
```

값이 없거나 정확히 `1`이 아니면 다음 경계가 적용된다.

- Manager 공급자 목록에서 실험 공급자를 제외한다.
- Manager 연결, 프로필 전환, 주 사용 변경 호출을 거부한다.
  (연결 해제·복구는 아래 정리 예외에 따라 고객 모드에서도 허용한다.)
- 실험 공급자의 API 발급 페이지를 열지 않는다.
- StockLens 상태 조회(status) 응답에서 실험 공급자 레코드와 주 사용
  표기를 제외한다. 주 사용이 실험 공급자로 남아 있으면 고객 모드
  응답에는 주 사용 없음으로 보고한다.
- StockLens 분봉 도구 설명과 허용 `source` 목록에서 실험 공급자를 제외한다.
- StockLens 연결 CLI의 공급자 목록과 신규 연결 동작에서 실험 공급자를 제외한다.
- 기존 상태 파일의 주 사용 공급자가 실험 공급자여도 `auto`가 그 공급자로 라우팅하지 않는다.

기존 자격 증명 정리를 막지 않도록 연결 해제와 복구 동작은 고객 모드에서도 허용한다. 전체 정리는 Manager의 제품 삭제 흐름을 통해 계속 가능하다. 개발자 모드에서는 기존 어댑터와 내부 테스트가 그대로 동작한다.
